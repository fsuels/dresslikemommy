# AI Sourcing Standard (Mirror Rule)

Owner: Francisco Suels  
Applies to: DressLikeMommy strategy, marketing, product, and operations guidance

## Core Rule
Not all information has equal value. Recommendations must prioritize:
1. **Source quality / credibility**
2. **Recency / up-to-date relevance**

## Required Sourcing Order
1. Primary sources (official docs, first-party data, direct platform guidance)
2. Leading experts and top companies in the domain
3. Top universities / peer-reviewed research when relevant
4. High-quality secondary analysis only when corroborated

## Recency Gate (Mandatory)
Before recommending actions, verify guidance is current for the present market/platform conditions.
- Reject stale tactics that are obsolete in 2026.
- For fast-changing topics (AI, ads, medical/business advice), explicitly check publication/update date.

## Shopify/Marketing Application
For DressLikeMommy recommendations:
- Use current platform behavior and latest best practices
- Prefer high-credibility, current evidence over legacy playbooks
- Avoid outdated strategies even if once common
