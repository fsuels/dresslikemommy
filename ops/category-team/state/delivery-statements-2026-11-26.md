## Method and limits

- Method: Admin GraphQL reads only (translatableResources with 20 locale aliases for ARTICLE, PAGE, SHOP_POLICY, COLLECTION, PRODUCT, SHOP, DELIVERY_METHOD_DEFINITION, EMAIL_TEMPLATE, MENU, LINK, BLOG, ONLINE_STORE_THEME*, plus articles/pages/collections/products metadata and shop/product metafield definitions). Theme read from origin/main c02a57e (git archive), not the dirty checkout. No storefront requests, no writes.
- Not readable: shop { shopPolicies } (no read_legal_policies scope; the same six policies were read through translatableResources SHOP_POLICY, English + 20 locales), deliveryProfiles (no read_shipping scope: express rate existence inferred from the two translatable method definitions), order/shipping notification email bodies beyond the translatable subject/body fields scanned (no day counts found).
- Metafields: custom.made_to_order_days is the only delivery-related definition (integer, used by the theme). Shop metafields SEOMetaManager title/description (home, collections/all, search) carry no shipping text. 20k product metafield translations were not enumerated; no definition carries shipping prose.
- Counts are statement rows = resource x field x locale for flagged patterns; the OK count is distinct English sentences that mention shipping, delivery, handling, processing, tracking, express or estimates (returns windows included), so it is a coverage figure, not a promise count.
- Sensitive observation, no action taken: shop metafields on the store hold third-party app keys in plain strings readable with this token; they were not copied anywhere.
