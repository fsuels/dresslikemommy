## Defects, ranked

1. Italian PDP shows the English Christmas order-by line. Likely the Christmas line snippet or its locale string (`.dlm-christmas-order-by`; the text was not found in repo snippets, sections, assets or locales, so check the hardcoded string in the theme JS/liquid that renders the neutral line, and add `locales/it.json` text). Other non-English locales (cs works) should be spot-checked.
2. Home category tile shows "Translation missing: en.sections.home_category_copy.caption_mommy_me" on the live site (US and IT, mobile and desktop). Repo HEAD `locales/en.default.json` line 881 already has `caption_mommy_me` under `home_category_copy`, so the live theme differs from the repo (not synced, or a store-side locale override is shadowing it); template `snippets/home-category-localized-copy.liquid` builds the key.
3. Mobile PDP main photo is delivered as a 311x552 file (currentSrc asked `width=713`) and shown at 373x664 css px on a dpr 2 screen, so it is upscaled and soft; desktop got 672x1194. Likely the mobile `sizes`/srcset in `snippets/product-thumbnail.liquid` / `sections/main-product.liquid` or the source asset resolution; not confirmed which. Natural ratio, no crop.
4. Red Heart builder mini measurement card has cm/in pills 24x13 px (below the 44px target used in the chart toggle). Snippet is in the product-matching-set (`.product-matching-set__...`) code.
5. Unit default is inconsistent for a US shopper: Reindeer chart opens in inches, Red Heart chart in cm.
6. Stray "Loading..." text in the cart family tile DOM (drawer and /cart).
7. About 103px blank gap on the Reindeer PDP between "Imported" and the similar-styles box (below-the-fold, cosmetic).
8. First paint after navigation on PDPs showed an empty photo area in 3 of 5 screenshots taken immediately after load (loaded in the next frame; likely lazy fade-in, may be tool timing).
