The derived brief exposes the sourced goal, current task inventory, completed milestones, remaining steps, relevant owners/claims and historical evidence. Default JSON retains detailed records on demand. It does not transfer another task's claim or grant live-write authority.

Completed work and blockers must be checkpointed in the existing task queue/worklog. No new business-state cache or competing dashboard was introduced.

Personal tabs, foreground controls, clipboard paste and browser-wide settings are not an automatic recovery path. A browser availability failure stops that lane while independent work continues.
