## What Is Missing

The Google Ads Python client needs a local API config. Google Ads Editor being installed does not provide this config to scripts. Editor can still help with manual bulk-file workflows, but it does not expose the API developer token, OAuth client secret, or refresh token needed by `google-ads`.

Required config values:

- `developer_token`: from Google Ads API Center, usually on a manager account.
- `client_id`: OAuth client ID from a Google Cloud project.
- `client_secret`: OAuth client secret from that same Google Cloud project.
- `refresh_token`: generated by authorizing the Google Ads user/account through the OAuth flow.
- `login_customer_id`: optional manager account ID without dashes, only needed if the API access must go through a manager account.

Current target customer:

- Customer/account ID for the forecast command: `3990976848` (`399-097-6848 dresslikemommy.com` in the Ads UI).

## How To Get The Values

High-level path:

1. In Google Ads, an admin/manager user gets or applies for a Google Ads API developer token in API Center.
2. In Google Cloud Console, create or reuse an OAuth client for an installed/desktop app.
3. Use the official Google Ads OAuth flow/example to generate a refresh token for the Google Ads user who can access account `399-097-6848`.
4. Copy the values into the local config file above.
5. Run the check command. If it returns `ready: true`, rerun the forecast command.

If there is no developer token yet, that is the real account-level setup task. It is not solved by Google Ads Editor.
