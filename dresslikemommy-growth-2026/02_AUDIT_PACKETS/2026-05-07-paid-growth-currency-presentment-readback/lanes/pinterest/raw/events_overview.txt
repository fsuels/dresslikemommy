Custom events are now available
Pinterest has added custom events to provide more flexibility in how you measure and optimize campaigns. Custom events can provide you with deeper insights and more accurate reporting to help you meet your business goals. Set up your custom events to start using them today. Learn more
New standard event types available
We've added six new standard events, including Contact, Schedule, FindLocation, CustomizeProduct, SubmitApplication and StartTrial. These new event types will help provide you with more accurate reporting and insights.
Note: If you were already sending these event types to Pinterest but they previously mapped to other events, you'll start to see your events categorized under these new event types moving forward.
