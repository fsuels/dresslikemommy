    Informações de envio
   
   
     Informações de envio 
 Na  Dress Like Mommy , somos uma loja online que envia looks combinando para família aos destinos disponíveis no checkout por meio de nossos parceiros de envio e preparação de pedidos. Veja como confirmar envio, prazo de entrega e rastreamento antes de comprar. 

 Opções de envio grátis e pagas 
 Os métodos e tarifas de envio disponíveis aparecem no checkout antes do pagamento. O envio padrão é grátis quando um método padrão grátis é exibido para o seu destino. Opções expressas ou pagas podem estar disponíveis para alguns endereços. 

 Para onde enviamos 
 A disponibilidade de envio depende do país/região e do endereço informados no checkout. Se o checkout mostrar um método de envio para o seu endereço, podemos enviar para lá pelo método e tarifa exibidos. 
 Se o seu destino não aparecer no checkout, ou se nenhum método de envio for exibido, escreva para  info@dresslikemommy.com  antes de fazer o pedido. 

 Processamento e prazos de entrega 
 Os pedidos são processados em 1-3 dias úteis após a confirmação do pagamento. Durante feriados, promoções ou períodos de alto volume, o processamento pode levar mais 1-2 dias úteis. 
 As estimativas de entrega variam conforme destino, transportadora, processamento alfandegário e método de envio exibido no checkout. Confira o método e a estimativa no checkout antes de comprar. 
 O rastreamento pode levar 24-48 horas para atualizar depois que o número é emitido. 

 Rastreamento do pedido 
 Depois que o pedido for enviado, verifique seu e-mail para as informações de rastreamento. Você também pode usar o link de rastreamento no e-mail de confirmação de envio quando disponível. 

 Alfândega, tributos e impostos de importação 
 Para pedidos fora dos Estados Unidos, o país de destino ou a transportadora pode cobrar tributos de importação, impostos, taxas de intermediação ou encargos alfandegários. Esses custos são responsabilidade do cliente, a menos que o checkout diga explicitamente que estão incluídos. 
 Não podemos prever esses custos, marcar pedidos como presente ou reduzir o valor declarado de um pedido. Consulte a alfândega local antes de comprar.

window.addEventListener('DOMContentLoaded', () => {
  if (window.matchMedia('(min-width: 750px)').matches) {
    return
  }

  const handleCollapse = (heading) => {
    if (heading.classList.contains('block-collapsed')) {
      heading.classList.remove('block-collapsed')
      heading.setAttribute('aria-expanded', 'true')
      return
    }

    heading.classList.add('block-collapsed')
    heading.setAttribute('aria-expanded', 'false')
  }

  document.querySelectorAll('.footer .footer__blocks-wrapper .footer-block__heading').forEach((heading, index) => {
    const detailsContent = heading.nextElementSibling

    if (!detailsContent) {
      return
    }

    heading.classList.add('block-collapsed')
    heading.setAttribute('role', 'button')
    heading.setAttribute('aria-expanded', 'false')
    heading.setAttribute('tabindex', '0')

    detailsContent.setAttribute('id', `footer-block-index-${index}`)
    heading.setAttribute('aria-controls', `footer-block-index-${index}`)

    heading.addEventListener('click', () => {
      handleCollapse(heading)
    })

    heading.addEventListener('keydown', (event) => {
      // Only handle Enter and Space keys; ignore other key presses
      if (event.key !== 'Enter' && event.key !== ' ') {
        return
      }

      event.preventDefault()
      handleCollapse(heading)
    })
  })
})
