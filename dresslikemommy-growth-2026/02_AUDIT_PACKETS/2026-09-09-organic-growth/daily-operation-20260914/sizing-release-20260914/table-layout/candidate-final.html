Shopping matching outfits gets easier when you treat sizing like a plan instead of a guess. The biggest mistake families make is assuming everyone should order the same way just because the print matches. In reality, mom's fit needs, kids' growth room, and dad's preferred ease can all be different. The best approach is to start with measurements, compare each item to the product page details, and shop one person at a time inside Matching Outfits.

If the product's size chart leaves a question unanswered, contact us before ordering. Include the product name, the selected wearer, and the measurements you need help interpreting.

Start with the right measurements

Start with the size chart for the exact piece you want to order. Check which measurements it asks for and whether it describes body measurements or garment measurements. Follow those instructions and use the same units as the chart. A flat garment width is not the same measurement as a body circumference. If the measurement method is unclear, ask for clarification before choosing a size.

Adult women's sizing: check the chart for the selected piece

For mommy-and-me dresses, tops, and coordinated sets, compare your measurements with the chart for the specific adult piece. Check each listed measurement rather than selecting a size from its letter label or how the outfit looks in a photo. If your measurements fall across different sizes, or the chart does not explain the fit you need, request help before ordering. Do not assume that choosing a larger size will resolve every fit question.

Kids sizing: toddler through teen

Measure each child separately using the dimensions requested by the selected product's chart. Use current measurements; an age label alone does not establish fit. Check the available child sizes on that product rather than assuming that every matching style includes the same age range.

If the outfit will be worn with another layer, or you are planning for a later date, explain that when asking about fit. Avoid automatically ordering a larger size for future growth. The product's measurements and any verified fit instructions should guide the choice.

Men's sizing for daddy-and-me outfits

For daddy-and-me shirts and other adult pieces, check the measurements on the exact product page. A familiar S, M, L, or XL label is not enough to confirm the fit of a different item. If the chart gives garment measurements, you can compare a garment that fits well only when you use the same measurement method. If the chart gives body measurements, follow its body-measuring instructions instead.

What to do when a size is unclear

  • Recheck the exact product chart, its units and its measurement instructions.
  • Use verified product details rather than guessing the fit or stretch from a photo.
  • Ask for help if measurements fall across sizes or the chart is incomplete.
  • Check the selected wearer, piece, size and quantity on each cart line before checkout. Matching items may require separate selections; confirm what the product includes.

The best final step is to build the cart slowly, checking each family member against the product page rather than treating the whole set as one sizing decision. Start with Matching Outfits, and contact us if the product's sizing information needs clarification before ordering.
